\chapter{The Three Pillars}

\section{Pillar I: Manifest (Structure)}

The Manifest defines the structural baseline of the ATUM\_ATOM system.
It serves as the authoritative record of all linked repositories,
governance boundaries, and integration points.

\subsection{Definition}

A Manifest is a SHA256-hashed directory structure that captures:
\begin{itemize}
  \item Repository names and roles
  \item Languages and purposes
  \item Integration status
  \item Governance boundaries
\end{itemize}

Using EDDSA, the Operator signs the Manifest to prevent tampering.

\section{Pillar III: Seal (State)}

The Seal captures the state of the Codex at binding time.
It includes drift detection, repository status, and operator attestation.

\subsection{Contents}

\begin{itemize}
  \item Timestamp of binding
  \item Repository activity log
  \item Drift detection report
  \item Operator attestation
  \item SHA256 hash of seal
\end{itemize}

\subsection{Drift Detection}

Drift occurs when:
\begin{itemize}
  \item Repository commits > 10 since last seal
  \item Repository dormancy > 30 days
  \item Manifest structure changes without verification
  \item Unauthorized modifications detected
\end{itemize}
